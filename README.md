# Library Management Project

A C++ library-management exercise covering borrowing periods for magazines and reference materials, with different borrower types such as students and professors.

## Source archive

The project is stored in [`A6-810100188.zip`](A6-810100188.zip). Download or clone the repository, then extract that archive into a separate working directory.

## Getting started

Inspect the extracted source, build files, and bundled instructions to determine the compiler, dependencies, assets, and entry point. The repository does not currently provide an unpacked source tree or a verified build command.
